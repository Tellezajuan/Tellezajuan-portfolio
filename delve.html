Delve · a game prototype

A daily dungeon game: easy enough for coffee, worth coming back to.

Think Wordle meets a dungeon adventure: one short run a day, a few risky choices, and a shared weekly world you can compare with friends.

I built it because I wanted to play it. It’s a working prototype I play on my own computer; it isn’t publicly released yet.

The loop Five floors a day, four classes to play, and a boss every Friday. A casual player finishes a quick run; a committed player chases a better route than their friends.

Why I made it

Casual to start. Hard to master. Fun to compare.

You pick a class, enter the same dungeon as everyone else that week, and choose one of three doors on each floor. The depth comes from your route: which risks you take, which abilities you find, and whether you save enough to face Friday’s boss.

That’s the mix I wanted: no long sessions, but enough personality that a result can start a conversation in a group chat. Play quickly, then come back because a friend took a different route or your trophy shelf still has a gap.

The loop in one sentence Five floors, one shared weekly dungeon, four classes, and a Friday boss give a casual player a complete session and a committed player a harder route to compare.

The habit loop

What brings someone back tomorrow.

Daily
One short run a day, so there’s always a reason to open it and never a reason to binge.
Shared
Everyone plays the same dungeon that week, so a friend’s route is directly comparable to yours.
Shareable
Each day ends with a result you can paste into a group chat, the same trick that helped Wordle spread.
Weekly peak
A Friday boss and a trophy shelf give the week an ending worth planning toward.
What it took

The small loop took more judgment than the feature list suggests.

Why I built it
Because I wanted to play it. It uses the same instincts as my marketing work: keep it clear, and be honest about the gap between a good build and a proven audience.
How long
Built mostly in August 2026, going by the project’s file dates.
Hardest part
Making five floors, four classes, a weekly boss, and seven color tones still feel like one short, easy session.
Latest change
A light “paper” tone. Every color in the game comes from one palette table, so a light version took one new palette, not a redesign.
Do differently
Set up the release checklist earlier, before polishing screens that might still change.
Where it stands

Small on purpose. Honest about what’s next.

It runs and it’s fun. Sharing it takes a few more steps.

Prototype A personal project A fun, small game I built to play. No claims about sales, players, or growth.
Not released Runs on my computer A public release comes after its release checks are finished.
